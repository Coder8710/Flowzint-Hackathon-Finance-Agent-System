# Frontend AI Agent Context

## Architecture Overview
The frontend is a modern web application built using **Next.js (App Router)** and **React**. It serves as the user-facing analysis console for the Flowzint Finance AI. It is designed to take user inputs (stock ticker, risk tolerance, investment horizon) and display the detailed multi-agent report generated by the backend.

## Core Technologies
- **Framework**: Next.js (React 18+)
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Key Directories
- `app/`: Contains the Next.js App Router structure. `page.tsx` is the primary entry point containing the main layout and state management for the analysis dashboard.
- `components/`: Reusable UI components used to render the various parts of the financial report (e.g., score cards, agent findings, charts).
- `lib/`: Contains utility functions and shared code.
  - `api.ts`: Houses the API client logic for making HTTP requests to the FastAPI backend.
  - `types.ts`: Defines TypeScript interfaces that map to the backend's Pydantic models, ensuring type safety across the stack.

## Data Flow
1. The user submits a query through the UI.
2. The frontend client (`lib/api.ts`) sends a POST request to the backend's `/analyze` endpoint.
3. While waiting, the UI displays a loading state to account for the time it takes the backend AI agents to process the data.
4. Upon receiving the `AnalysisResponse`, the frontend updates its state and dynamically renders the final investment thesis, the master agent's recommendation (Buy/Hold/Sell), and the individual specialist agents' findings.

## UI/UX Guidelines
- The design leverages **TailwindCSS** for responsive, mobile-friendly layouts.
- It is intended to look sleek and professional, catering to a financial/fintech aesthetic.
- Components should strictly type their props using the interfaces defined in `lib/types.ts`.
